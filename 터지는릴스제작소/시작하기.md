# 시작하기

1. 이 폴더(`터지는릴스제작소`)를 내 컴퓨터의 원하는 위치(예: 문서)에 둔다.
2. Claude 데스크톱 앱 → **Cowork** → 폴더 선택에서 이 폴더를 연결한다.
3. `CLAUDE.md`의 `(채울 것)` 부분을 고친다.
4. `01_터진릴스/`에 터진 릴스 3~5개를 넣는다. `01_예시` 폴더를 복사해서 릴스 하나당 폴더 하나로 만든다.
   `_안터진릴스/`에도 비교용 2~3개를 넣는다.
5. Cowork에 **[공식 만들기]** 프롬프트를 보내고, 나온 공식을 직접 읽고 고친다.
6. **[주간 패키지]** 프롬프트로 한 번 직접 돌려 본다.
7. Cowork의 Scheduled(`/schedule`)에 **[주간 패키지]** 프롬프트를 매주 일요일 21시로 등록한다.
   ⚠️ 예약 시간에 컴퓨터가 켜져 있고 Claude 앱이 실행 중이어야 한다.
8. 매주: 결과물로 촬영·업로드 → 올린 릴스의 인사이트를 `05_성과피드백/`에 넣는다.

---

## [공식 만들기] 프롬프트 (처음 한 번)
```
CLAUDE.md를 먼저 읽어. 그다음 01_터진릴스와 01_터진릴스/_안터진릴스를 비교 분석해서
02_공식/터지는공식.md의 빈칸을 채워줘. 훅 유형, 길이, 구성, 자막, 업로드 시간, CTA를
수치와 근거(어느 릴스에서 나왔는지)와 함께 정리하고, 확신이 낮은 항목은 따로 표시해줘.
```

## [주간 패키지] 프롬프트 (매주 예약)
```
CLAUDE.md와 02_공식/터지는공식.md를 먼저 읽고 시작해.
① 05_성과피드백에 아직 반영하지 않은 자료가 있으면 분석해서 02_공식을 업데이트하고,
   변경 기록에 날짜와 이유를 남겨. 반영한 자료 파일명 앞에는 "반영완료_"를 붙여.
② 03_소재에 영상이 있으면 그 영상을 쓰는 기획을 우선으로 해.
③ CLAUDE.md 규칙과 04_주간결과물/_결과물_템플릿.md 형식대로 이번 주 패키지를 만들어서
   04_주간결과물/이번주차(예: 2026-W45) 폴더에 저장해.
```
