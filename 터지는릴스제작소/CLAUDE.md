# 터지는 릴스 제작소 — @yool24.7

> 작업을 시작할 때마다 이 파일과 `02_공식/터지는공식.md`를 먼저 읽을 것.

## 계정
- 주제/분야: (채울 것 — 예: 타로, 연애운, 오늘의 메시지)
- 타깃: (채울 것 — 예: 20~30대 여성, 연애 고민)
- 톤: (채울 것 — 예: 친한 언니 반말, 다정하지만 단호)

## 고정 규칙
- 길이: 15~30초. 훅은 첫 1.5초 안에
- 자막: 한 화면 최대 2줄, 한 줄 14자 이내
- 마지막 3초: 저장 또는 댓글 유도
- 형식은 항상 `02_공식/터지는공식.md`를 따를 것
- 공식에 없는 새 시도는 주당 1개까지만, "실험"이라고 표시할 것

## 금지 표현
- 공포 조장 ("큰일 나요", "꼭 봐야 해요, 안 그러면…")
- 단정적인 미래 예언, 의학·법률·투자 조언
- (내가 안 쓰는 말투나 단어 채울 것)

## 폴더 역할
- `01_터진릴스/` 터진 릴스(릴스당 폴더 하나). `_안터진릴스/`는 비교용
- `02_공식/` 분석해서 뽑은 공식. 업데이트할 때는 아래 변경 기록에 날짜와 이유를 남길 것
- `03_소재/` 이번 주에 찍은 원본 영상(없을 수도 있음)
- `04_주간결과물/YYYY-Www/` 매주 패키지 저장 위치 (예: 2026-W45)
- `05_성과피드백/` 결과물로 올린 릴스의 실제 성과

## 결과물 형식
`04_주간결과물/_결과물_템플릿.md` 형식을 따른다.
- 릴스 5개
- 맨 위에 "이번 주 추천 1순위와 이유"
- 각 릴스마다 공식의 어떤 패턴을 썼는지 한 줄로 표시
